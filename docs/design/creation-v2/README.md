## 使用边界（重要）

1. **图中文字由生成模型绘制**，会出现错字、错词、英文混排；生产实现一律用真实文案与现有图标体系。
2. **图中的模型名、积分数字、时间戳是占位**（例如 `MiniMax-Video-01`、`1,200 积分`），**不是**我们的选型或定价。
3. 图里出现的按钮**不代表能力已具备**；能否点亮以 S1 能力目录为准，没有能力声明就不开放。
4. 三张图均为 1536×1024（3:2），仅用于方向对照；实际验收尺寸是 1366×768 / 1920×1080。
5. 与规格冲突时，**以 [CREATION-EXPERIENCE-DESIGN](../CREATION-EXPERIENCE-DESIGN.md) 的 §7 为准**，不以图为准。
