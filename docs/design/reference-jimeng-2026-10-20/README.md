## 对 S5-B4 的采用结论

- **B4b 视觉**：采用「炭灰底 + 无衬线 + 媒体优先 + 单行低干扰参数」；颜色仍用 `docs/CREATION-EXPERIENCE-DESIGN.md §3.2` 的 `#111315 / #1C1F22 / #262A2E` 与青色 `#67DCF2`，不照搬即梦的蓝色与会员色。
- **B4c 状态**：采用「状态与当前预览分开」：排队/运行/失败是任务状态，查看的是上一次成功产物；版本列表要有「当前」文字，不只靠底色。
- **B4d 键盘/焦点**：即梦本轮的菜单是鼠标操作；**没有**用它证明键盘路径。我们的方向键/Enter/Esc、焦点陷阱与回焦仍按 AC5-B4 自己验收。
- **B4e 导航**：即梦没有「退场路由」问题；旧入口说明仍按我们 D62 处理。
- **B4f 窄屏**：没有在 375px 下采集即梦；窄屏验收只以我们应用的 375×812 实测为准。
- **参考图不是验收证据**：我们的三档视口截图、键盘流程与入口清单在 B4g 单独产出，不放本目录。

## 明确不采用

- 会员/积分/充值/商城体系（PLAN D59）。
- 7 种创作类型、数字人、动作模仿、音乐/音频生成。
- 全能参考、智能多帧、智能编辑、超长视频、局部重拍、智能超清等未接通能力。
- 探索/主体/公开社区/协作房间。
- 把「有按钮」当作「能力已实现」。
