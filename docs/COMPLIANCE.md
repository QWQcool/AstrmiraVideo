# 合规台账

> 负责人：平台/安全。**每次接入新模型、新素材源、新供应商时更新本表。**
> 本表是工程决策的依据，不是法律意见；重大事项请咨询专业人士。

## 1. 模型与引擎

| 对象 | 关键条款 | 我们的义务 / 状态 |
|---|---|---|
| **MiniMax H3**（开源权重） | ① 商业产品界面须**显著标注 "MiniMax H3"**；② 年收入 > 2000 万美元需另行书面授权；③ 产出与权重**不得用于训练非 H3 系模型**；④ **开源权重暂不含欧盟、英国、美国、韩国**；⑤ 托管给他人使用须落实内容安全措施 | ✅ 界面与导出物固定标注（现在就做，成本为零）<br>⏳ 年收入台账（未触发门槛）<br>✅ 使用条款明示禁止训练用途<br>✅ 服务器与团队所在地区：中国（不受限）<br>⏳ 对外提供服务前补内容安全机制 |
| **火山方舟 Seedance / 豆包系列** | 平台 AUP + 内容审核 | 不绕过上游审核 |
| **即梦开放平台** | 平台协议 + AK/SK 签名调用 | Key 服务端托管，不外泄 |
| **ComfyUI** | **GPL-3.0**（待核实） | ❌ 不内嵌其代码；✅ 仅通过 HTTP 调用独立服务 |
| **MiniMax H3 量化/加速社区包**（Civitai 等） | 各自许可，部分为第三方整合包 | ⏳ 使用前逐个核实；**不使用宣传"破限制/越狱"的包** |

## 2. 素材与内容

| 对象 | 关键条款 | 我们的义务 / 状态 |
|---|---|---|
| Pexels / Pixabay 素材 | 可免费商用、通常无需署名；但**人物肖像与品牌标识存在限制** | ⏳ 选材过滤（规避明显商标/肖像风险素材）<br>✅ 产物标注素材来源 |

## 3. 开源代码使用边界

| 对象 | 结论 |
|---|---|
| Dify | 使用 modified Apache-2.0：多租户限制（本项目**不做多租户服务**，不触发）；**前端 LOGO 条款**（只要不复用其 `web/` 代码即不适用）；**⚠️ 交互设计受外观专利保护 → 不照搬其 UI 视觉与布局**；若复用非前端代码需在 NOTICE 保留版权声明 |
| FSL-1.1 许可项目（Vidia 等） | 限制竞争性使用 → **不复刻代码** |
| MIT / Apache-2.0 项目 | 可复刻，但需登记来源（见 `UPSTREAM.md`）并保留版权声明 |
| 本仓库自身 | MIT |

## 4. 数据与用户密钥（BYOK）

- 用户自带的供应商 Key：**默认只保存在内存（会话级）**；勾选保存则用服务端主密钥 AES-GCM 加密入库
- **永不回显**（仅显示 `sk-****abcd`）· 前端不写 localStorage · 日志强制脱敏
- 传输强制 HTTPS
