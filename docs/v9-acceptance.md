## 1. AC1 · 四个（实为五个）一级路由 + 剪辑台

**断言**（冒烟 `[1b]` 组）：默认视图 `#/workbench`（无 hash 时 `replace` 进入）→ 侧栏五项 → 五视图切换且 `aria-current` 跟随 → **浏览器前进/后退可用** → **刷新保持当前视图** → 剪辑台 `#/edit` 可直达且**不进侧栏** → 未知 hash 落**兜底页**（不白屏、不静默重定向）→ 兜底可回工作台。

**结果**：9 条断言全绿（实测输出见提交记录）。**破坏性验证命中**：临时把 `#/library` 从注册表删掉 → 访问该 hash 落到"未知视图"（非白屏）；还原后冒烟重新全绿。

## 2. AC2 · 总览四卡与原始数据逐一对账

**断言**（冒烟 `[6b]` 组）：四卡齐全；最近成片九宫格有内容；最近操作 feed 有内容；**四卡数字与现场重算的 `/api/history` 逐一比对**——今日生成、成功率（分母=最近 50 条里的终态任务）、队列中、存储占用（`totalBytes` → `formatBytes`）、九宫格数量 `= min(成功任务数, 9)`。

**实测**：今日 1 / 成功率 100% / 队列中 0 / `totalBytes=619826`（界面「605 KB」）/ 九宫格 1 = min(1, 9) —— 全绿。

**为空/异常时**：未加载完成显示**骨架屏**（不显示 0 / — 这类"看起来像真数据"的占位）；读取失败给出可读原因与重试；没有成片时给空态引导。

## 3. AC3 · 动效体系（7 项）与 reduced-motion

**断言**（冒烟 `[7b]` 组）：**双 context 对照** —— 同一份产物在 `reducedMotion: 'reduce'` 下视图入场与卡片级联被压到 `1e-05s`，在 normal 下为 `0.26s`（**证明断言不是恒真的**）；生成中微光晕的挂接规则（`data-status=running` → `breathe-glow`）存在。

**7 项落位**：① 侧栏收展（唯一布局属性过渡，同样在 reduce 下归零）② 视图切换 fade+slide ③ 卡片 40ms 级联 ④ 生成中呼吸微光晕 ⑤ `star-gather` 提级到播放器中央可重播 ⑥ 卡片 hover 浮起 2px + 金描边 ⑦ 骨架屏扫光。

**零孤置**：视觉自检按登记表逐项检查（**11 个 keyframes 均有功能位**；新增 3 个显式登记，计划外的会被拦）。

**破坏性验证命中**：摘掉 `breathe-glow` 的挂接 → 自检报 `keyframe breathe-glow 没有任何功能位使用`；**并因此揪出自检自身的缺陷** —— 它按纯文本匹配，注释里的 `animation:` 也算挂接（漏检方向），已修（判定前剥块注释且保留行号）。

**断言**（冒烟 `[6c]` 组）：搜索**不存在的词** → 空态文案（**固化的破坏性验证**，而不是原样显示全部）；清空搜索恢复；「失败」筛选与 API 现算对账（含 `cancelled`）；**时间正序的 DOM 首条 = API 现算最旧**；详情抽屉「复用参数」把提示词**完整回填**到工作台。

## 6. AC6 · 剪辑台（trim → concat → xfade、抽帧、EDL）与"零上游调用"

**集成测试**（`pipeline/editExecutor.test.ts`，**真 ffmpeg + 真 SQLite + 桩队列**，3 条）：
- `trim(0→3) → concat(另一段 5s) → xfade(fade 0.5s)` → 产物 ffprobe **7.5s ±0.2s**（3+5−0.5）、**视频与音轨齐备**；心跳记录了推进过程；
- 抽帧落 `outputs/assets/<assetId>.jpg` 并写回 `extractedAssetIds`；
- 源成片不存在 → `TASK_NOT_FOUND`（不让 ffmpeg 报错）。

**破坏性验证命中三条**：`endSec ≤ startSec` → **400 `INVALID_REQUEST`**（不是 500）；抽帧时间点超片长 → **如实报错且不产空文件**（首版 ffmpeg 的报错不可读，改为先探片长再给"多少秒超出多长的片"）；拼接素材缺失 → 404 且不落空产物。

**零上游调用**（硬要求）：`edits.ts` 与 `editExecutor.ts` **不 import 任何 provider、不读凭据** —— 测试里有一条**源码级结构断言**盯着这两件事；执行器跑在 `local` 轨（本地互斥 1）且**不走防线 5 冷却**。

**冒烟 `[6e]`**：真跑一次剪辑（裁剪 + 抽帧）→ 产物在剪辑台里可播放、出现在历史里带 `origin.kind='edit'`、`extractedAssetIds` 落账 1 个、`/media` 返回 **206**。
