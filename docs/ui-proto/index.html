缓慢推近运镜t2v · i2v
镜头缓慢推近主体，景别由中景过渡到近景，背景虚化逐渐加强，运动平稳不抖动。
建议 ≤5s 坑：5s 内容易走不完，建议 ≤5s
低角度环绕运镜t2v
低角度缓慢环绕主体半圈，掠过主体的材质细节，画面焦点始终锁定主体中心。
建议 5s 坑：环绕过快会产生拖影
丁达尔光束光线t2v · i2v
强烈逆光，可见丁达尔光束穿过空气中的微尘，主体边缘被勾出明亮轮廓光。
建议 5s 坑：过曝会丢失主体细节
暖冷对比光线t2v
主体被 2700K 暖光包裹，环境为冷蓝霓虹余光，两者形成明确冷暖对比，浅景深。
建议 5s 坑：冷暖界线要清楚，否则整体发灰
雨夜氛围氛围t2v · i2v
雨夜街道，霓虹倒映在湿滑地面，空气中可见细雨与蒸汽，整体低调暗部保留层次。
建议 5s 坑：暗部过暗会糊成一团
节奏卡点节奏t2v · v2v
前 2 秒缓慢铺陈，第 3 秒出现明确动作转折，最后 1 秒定格收束，动作节拍与镜头切换对齐。
建议 5s 坑：转折过早会显得仓促
