## （一）推荐档位与本地引擎配置（Tier 0~3）

> **本节是档位文案的唯一详写处**：前端展示的推荐说明为其投影，改则同步（台账 PLAN §9-B6）。

下表是**选型建议**，**不是探测结论**——系统不扫描你的硬件，也**不替你判断设备能力**（决策见 PLAN §6-D22）。`GET /api/providers/status` 只报告**本服务自身**的本地引擎配置状态：env 有没有兜底 Key、本地引擎有没有被部署者显式启用。

| 推荐档位 | 硬件特征（显存） | 本地可部署评估 | 建议 |
| :--- | :--- | :--- | :--- |
| **Tier 0**（无独显/核显） | 无独立显卡 或 < 6GB | 无法运行视频 DiT 模型（必 OOM） | 推荐【云端 Seedance】；本地开关**保持可选、不置灰**——选了但服务端未配置本地引擎时会返回 `PROVIDER_UNAVAILABLE` |
| **Tier 1**（入门档） | 6~10GB | 轻量量化模型（LTX-Video / CogVideoX-2B / Wan2.1 1.3B）【待验证】 | 日常小样；重要成片切云端 |
| **Tier 2**（主力档） | 12~16GB | MiniMax H3 NF4（Disk Offload）【已验证实测：单步约 8~14 分钟，适合离线长任务】 | 本地离线主力，0 Token 成本（极慢）；实时出片推荐云端 |
| **Tier 3**（旗舰档） | ≥ 24GB | 全精度/高分辨率/复杂工作流【待验证】 | 极速本地生产 |

**双轨姿态**：默认走云端；本地轨需**部署者显式配置启用**（服务端 `.env` 的 `EXPOSE_HOST_LOCAL_TRACK=1` + `H3_WORKDIR` / `COMFYUI_BASE_URL`）。未启用时 `local.available:false`，`reason` 会如实说明是「本服务未配置本地引擎」还是「本服务未向访客开放本地轨」——**不会说"你的设备不支持"**。

## （二）双轨引擎接入

### 轨道 A：本地模型推理（两种路径）

**路径 1：接入已有环境**
- MiniMax H3：在设置面板填入工作目录（或设 `.env` 的 `H3_WORKDIR`，默认 `%USERPROFILE%\Desktop\MiniMaxH3`），点【测试连接】，系统调用该目录下 Python 校验 CUDA 与权重缓存；
- ComfyUI：填入监听地址（默认 `http://127.0.0.1:8188`），点【测试连接】，系统请求 `/system_stats` 拉取模型与节点状态。

**路径 2：一键部署脚本【规划】**
`scripts/setup_local_env.bat`（或前端【一键部署环境】按钮）：检查 Python 3.10~3.13 与 Git → 建 `.venv` → 国内镜像装 PyTorch CUDA + DiffSynth-Studio → ModelScope 拉权重 → 冒烟测试。

### 轨道 B：云端商业 API（火山方舟 · Seedance）

1. 登录[火山引擎控制台](https://www.volcengine.com/) → 火山方舟（ModelArk）→ 开通视频生成服务，生成 API Key；
2. 前端设置抽屉填入 Key，或配置 `.env`（键名见根目录 `.env.example`）；
3. 安全机制：Key 存于**你的浏览器**（默认 `sessionStorage`，关闭标签页即清除；可选 `localStorage`，表示你接受**明文存储**风险），随请求头 `X-Provider-Key` 发送；服务端只在转发瞬间**过手**，**不落盘、不写日志、不回显**（细则见 PLAN §7-1 与 CONTRACT §5「凭据传递约定」）。

## （三）四种生成工作流

![提示词扩写与 32 倍数裁切工作流](assets/03_prompt_and_video_workflow.jpg)

1. **T2V 文生视频（含台词人声）**：输入主体与动作描述即可。本地 H3 原生支持音频——对白用**直角双引号**包裹（`女孩说："快看，流星！"`），输出 MP4 直接合成立体声台词与环境音【已验证】；
2. **I2V 首帧图生视频**：拖入单张图作起始帧 + 运动指令。Smart Crop 自动居中裁切并规整为 32 的整数倍（如 832x480），避免 DiT 尺寸报错；
3. **FL2V 首尾帧过渡**：分别上传 First / Last Frame + 转场描述，生成平滑过渡镜头；
4. **V2V 参考视频重绘**：拖入参考视频 + 风格提示词，迁移镜头动作或风格。

## （六）FAQ 与避坑

**Q1：提示词写了对白，视频却没声音？**
H3 只识别直角双引号 `"` 包裹的对白；中文引号 `“”` 或无引号会被当作普通动作描述。

**Q2：各档显卡出片要多久？**
480x832 / 124 帧（约 5.2s）：Tier 2（16GB 显存）因采用 Disk Offload 磁盘换入换出，单步需 8~14 分钟，50 步需 7~10 小时【已验证实测】；Tier 3（24GB+ 显存无需 Disk Offload）约 2~4 分钟【待验证】；云端 Seedance 约 30 秒~1 分钟【待验证】。

**Q3：无卡服务器部署会报本地模型错误吗？**
不会。状态端点返回 `local.available: false` 并给出 `reason`，前端按 `reason` 展示说明。**探针只报告本服务的本地引擎配置状态，不会替你判断设备能力**——是否使用本地模型由你自己决定（推荐配置见 §一）。

**Q4：连续点生成按钮会怎样？**
触发 60s 防抖冷却，返回 `RATE_LIMITED`（错误码字典见 CONTRACT §6）。

**Q5：Key 会不会被服务端记录？**
不会**留存**——服务端过手即弃，不落盘、不写日志、不回显，日志中强制掩码。但必须如实说明：**Key 在转发时必然经过服务端内存**，因此"服务端绝不可信"的假设不成立，第三方托管部署请自行评估信任边界（决策见 PLAN §6-D23）。另外默认存 `sessionStorage`，**关闭标签页后需要重新填写**——这是"零留存"的代价。

**Q6：公网部署为什么看不到本地轨？**
本服务默认**不向访客开放 host 本地轨**（`EXPOSE_HOST_LOCAL_TRACK=0`）：本地推理单条成片可能耗时数小时，开放给公网访客会被免费算力滥用。自部署者需要本地轨时，在服务端 `.env` 显式开启并配置引擎路径（见 §二 轨道 A）。
