## 一、P3 · one-for-all 创作入口（台账 B41）【已完成 2026-10-08】

> 落地与本文的差异（如实记录）：① `@` 入口除"输入 `@`"外补了一个显式按钮「＠ 引用素材 / 成片」
> （可发现性 + 稳定的冒烟选器）；② 创作入口与工作台同做 **keepalive 常驻**（切视图不丢输入与任务卡）——
> 代价是隐藏副本会参与全局 DOM 查询，冒烟选器需限定 `:visible` / `.wb-keepalive:not([hidden])`；
> ③ 弹层打开与上传完成后都会**刷新素材池**（常驻视图不重挂载，否则新成片 @ 不到）。
> 契约 = **V2.7**（`GET /api/assets`），`contract.test.ts` 先红后绿；冒烟 [7d] 八条断言。

### 1.1 形态定稿（不再评审，直接施工）

**一句话：新默认首页 = 一个居中的"造梦盒"，把三栏工作台退为「专业模式」。**

- **路由与导航**：新增一级视图 `#/create`（创作），**默认视图改为 `#/create`**（PLAN §6 决策登记 = D39；
  Step 6-AC1 的"默认 = `#/workbench`"就此被 D39 取代，验收文档修订时注明）；`#/workbench` 保留全部
  现有能力与 Step 6 证据链，侧栏标签改为「工作台 · 专业」。侧栏顺序：创作 / 工作台 / 总览 / 视频库 / 配方库 / 日志。
- **首屏结构**（星尘暗黑美学，全部走 tokens，零硬编码）：
  1. 顶部 eyebrow + 一句话品牌位（不抄即梦文案，自写）；
  2. **意图输入框**（多行 textarea，自动增高；`@` 触发提及弹层；Enter 提交 / Shift+Enter 换行）；
  3. **提及 chips 行**（`@` 选中的素材渲染成可删除 chip：图片缩略图 / 视频封面 + ✂ 标记）；
  4. **配方 chips 横滚条**（复用 `packages/shared` 配方库数据，点按 = 骨架追加到输入框，
     逻辑复用 `lib/recipeInsert.appendSkeleton`）；
  5. **「更多设置」抽屉把手**（画幅 / 时长 / 清晰度 / 引擎 / seed；默认收起，选择结果以一行摘要可见）；
  6. **整页拖图/粘贴监听**：拖入或粘贴图片即上传 → 自动进 I2V（素材决定模式，见 1.2）。
- **提交后**：停留在 `#/create`，内联出现任务卡（进度 → 成片播放器，复用工作台中栏组件），
  附「去专业模式查看」链接。**不跳走**——一句话入口的沉浸感是这页的卖点。
- **BYOK 门控**：未配 Key 时提交按钮置灰 + 同屏写明去哪配（沿用工作台口径，不许只置灰不解释）。

### 1.2 `@` 提及与模式推断（核心逻辑，纯函数先行）

- **新文件 `frontend/src/lib/mentions.ts`**（纯函数 + 单测，纪律同 `lib/assets.ts`）：
  - `parseMentions(text)` → `{ cleanText, refs: MentionRef[] }`（chip 提交制：文本里的 `@xxx` 只是输入态，
    真正的引用是 chips 行的结构化数据——**不做裸文本解析当真相**，避免"@符号被截断/重名"歧义）；
  - `modeForRefs(refs)` → `GenerationMode`：0 素材 → `t2v`；1 张图 → `i2v`（首帧）；
    2 张图 → `fl2v`（先选=首帧、后选=尾帧）；含视频 → `v2v`（取第一个视频，**多余素材忽略且在界面明说**——不静默）；
    ≥3 张图 → 取前两张走 `fl2v` + 提示。
  - `assetsForRefs(refs)` → `VideoGenerateRequest['assets']`：图片 = 既有 assetId；
    成片/剪辑产物 = `task:<taskId>`（V2.6 已就绪）；**上传资产当 V2V 参考也保持 assetId 原形态**。
- **提及弹层候选**：资产（需新端点，见 1.3）+ 成片（`fetchHistory()` + `fetchHistory({kind:'edit'})`，
  接口已就绪）；键盘上下选择 / Esc 关闭 / 鼠标点选，aria 按 combobox 惯例。
- **一致性 AC 锚点**：同一组 refs 经由 `modeForRefs`/`assetsForRefs` 的结果，必须与三槽路径
  （`modeAfterSlotUpload`/`assetsForMode`）的语义**逐例一致**（单测矩阵复用既有 18 例的边界）。

### 1.3 契约变更（CONTRACT **V2.7**，先改契约再改代码）

- **`GET /api/assets`**【新增】：返回资产库清单（`{ assets: [{ assetId, kind, mime, size, url, createdAt? }] }`，
  按 `outputs/assets/` 目录扫描，与 `/api/upload` 清洗产物同口径；只读、同源、无敏感）。
  没有它，`@` 弹层列不出"以前上传过的图"（资产 ID 目前只存在于上传响应与任务快照里）。
- **§5 路由表 + §7 资产生命周期**同步一行。
- shared 新增 `AssetListResponseSchema`（改完 `pnpm build` rebuild shared）。

## 二、P4 · L2 只读血缘画布（台账 B42）

### 2.1 形态定稿

- **路由**：`#/canvas`（画布），侧栏一级入口（可灵把画布放一级，我们跟上）；默认视图仍是 `#/create`。
- **数据**：`fetchHistory()` + `fetchHistory({kind:'edit'})` 两路并发——**零契约变更**。
  血缘边全部从既有字段推导（纯函数 `frontend/src/lib/lineage.ts` + 单测）：
  - `origin.kind='edit'` → 源片 → 剪辑产物 的边；
  - `extractedAssetIds[]` → 任务 → 抽帧资产 的边；
  - `requestSnapshot.assets`（含 `task:` 引用）→ 资产/成片 → 新任务 的边。
- **节点**：成片卡（封面 + prompt 截断 + 状态点 + ✂ 徽标）、资产卡（缩略图 / 🎬）。
  点节点 → 右侧详情抽屉 + 动作按钮（**回填参数到工作台** / **✂ 送剪辑台** / **设为 V2V 参考**——
  全是既有路由与 hash 参数的复用，不新增后端能力）。
- **布局**：自写 DAG 分层（按派生深度分列、同列按 createdAt 排序，约 20 行），**不引 dagre**。
- **组件**：`@xyflow/react`（UPSTREAM #5 早已登记），**钉死版本号**；禁连线、禁删节点；
  节点可拖摆位（会话内，不持久化）。样式走其自带 CSS（vite 打包为本地资源，CSP `style-src 'self'` 兼容）。
- **空态**：无任务时给引导文案 + 跳 `#/create`。

### 2.2 任务拆解

| T | 内容 | 验证 |
|---|---|---|
| T1 | `lib/lineage.ts` 纯函数（tasks → nodes/edges）+ 单测（含孤儿节点 / 自引用 / 缺失源） | 前端单测 |
| T2 | 引入 `@xyflow/react`（钉版本）+ `#/canvas` 视图 + 分层布局 + 节点渲染 | 构建（确认进独立 chunk） |
| T3 | 详情抽屉 + 三个动作跳转 + 空态 | UI 冒烟新增第 [9] 节 |
| T4 | reduced-motion / 移动端降级（画布在窄屏给"去桌面看"的诚实提示而非硬塞） | 冒烟 |

### 2.3 AC（对接 PLAN §4 Step 8-AC6）

- 画布覆盖全部历史任务与剪辑产物的派生链（冒烟断言节点数 = 接口事实）；只读（无连线/删除交互）；
  空态文案；reduced-motion 归零；控制台零 error。

## 五、L1（单镜头主线）高价值余项盘点

按"风险 × 频率"排序，候选池全部来自 §9 台账（编号即链接）：

| 优先级 | 项 | 为什么现在值 |
|---|---|---|
| ① | **线上验收班车**（Step 6 / 7 / 8-P1P2 都等验收） | 不验收 = 没交付；100MB 与 `task:` 引用要随 CD 上线才生效 |
| ② | **B22 磁盘 LRU** | `outputs/` 只增不减；线上 4 核小机器的磁盘是**确定性会满**的运营风险 |
| ③ | **B32 真人素材体验收敛** | 上游隐私检测拒绝是 I2V/FL2V 的**高频真实踩点**（已有实测样本），前端前置引导成本低 |
| ④ | **B25 `keys/verify` 独立限流桶** | 公网探测面：verify 会向上游发请求，被刷 = 拿部署者服务器当探针 |
| ⑤ | **B18 Node 版本对齐** | 本机 v24 vs CI/镜像 22，半小时活，消除"本地绿 CI 红"漂移源 |
| 观望 | **B31 图片生成入口** | 产品面扩展（上游支持文生图），需独立能力位与计价口径，等拍板 |
| 观望 | **B38 独立音效素材** | 配合剪辑台音频轨；需先扩 `/api/upload` 白名单 + 清洗口径 |
| 观望 | **B39 legacy EDL 收敛** | 先看 `/api/edits` 真实调用量再决定删留 |

> 建议：P3/P4 之外**顺手搭 ②（B22）与 ⑤（B18）**——一个是线上定时炸弹，一个是零成本卫生。
> ③④ 等下一次用户报障或公网异常调用再触发（台账口径不变）。
